# General product information:

The equipment models Liebert NXrE150K and Liebert APM 150K are on line type uninterruptible power supply system with sine wave o/p for general use. And Liebert APM 150K is identical to Liebert NXrE150K except for model name. See block diagram below for details.

The system is designed as rack type, a standard frame with 10 standard module positions with corresponding connection methods for power module, bypass-monitor module or battery module which can be removed by service person (disconnection switch for battery module and bypass-monitor module provided, which will be opened before removing the module itself). The battery module and each other module were each type tested and have the same size but different connection method (different special shape connectors used on the rear side).

The amount and position of the modules is fixed during the process of manufacturing. Another special position for bypass-monitor module provided in the bottom of the frame, which can not be removed during service. For details of modules intended to be used in the UPS system and different configuration for module quantities and additional descriptions, see page 8-9 for details. The front panel (outer door) and area inside the door is considered as operator accessible area. External battery cabinet is optional and not provided with the UPS.

The UPS is designed as primary type. Please see the classification of circuit as below,

- Primary circuit: Battery input, charger, AC input and AC output circuit
- SELV circuit: front panel, Parallel connection port and EPO circuit

Therefore, double/reinforced insulation is designed for the whole system:

- Basic insulation between Primary circuit and earthed metal chassis/PCB trace
- Double/reinforced insulation between SELV circuit and primary circuit

# Ventilation of battery compartments

The required dimension for the ventilation openings will be calculated with the following formula:

A > K1 * Q

with Q = (0.054 m³/Ah) * n * I * C

where:

- K1 : constant factor of 28 h * cm²/m³
- Q : airflow in m³/h
- n : number of battery cells
- I : constant factor (0.2A/100Ah for valve regulated lead acid batteries)
- C : nominal capacity of the battery

With the specific data for the UPS the following dimension for the ventilation openings is required:

- n : 60 for battery module
- C : 8.5Ah for each battery

A > 28 h * cm²/m³ * (0.054 m³/Ah) * n * 0.2 A/8.5 Ah * C

A > 58cm² for battery module

# Verdict

The size of ventilation openings (125 cm² for each battery module) for the whole system exceeds the required airflow by far (as well as the UPS).

The open hole for the battery air exchange, which be made on the battery module case. Each battery module have more than 1000 holes. Each hole’s D size is 4.0mm. It is meet the requirement.
